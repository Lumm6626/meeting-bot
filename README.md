# 会议翻译助手（Teams Meeting Bot）

本地旁听 Teams 会议：实时识别多语种发言 → 翻译成中文 → 置顶字幕浮窗；
会议结束后自动生成双语逐字稿（Markdown）与中文会议纪要（Word）。

## 首次安装

1. 创建虚拟环境并安装依赖：
   ```bash
   python -m venv .venv
   .venv\Scripts\pip install -r requirements.txt
   ```
2. 复制 `.env.example` 为 `.env`：
   - `OPENCODE_API_KEY`：从 `C:\Users\<你>\.pi\agent\models.json` 中 provider
     `cc-switch-open-code-go` 的 `apiKey` 复制
   - `WHISPER_MODEL`：默认 `small`（本机快于实时）；追求精度可改 `medium`
     （慢于实时约 1.5 倍，字幕延迟变大）
   - `HF_TOKEN`：**可选**，仅说话人区分需要。到 https://huggingface.co/settings/tokens
     创建 token，并打开 https://huggingface.co/pyannote/speaker-diarization-3.1
     点击 "Agree and access repository" 接受使用协议；留空则关闭说话人区分
3. `python install_shortcut.py` 创建桌面快捷方式
4. 首次运行会自动下载语音模型（small 约 500MB，请耐心等待）

## 使用

1. 开会前：双击桌面"会议翻译助手"
2. 选择**音频源**（下拉框，默认「扬声器（线上会议）」）：
   - **扬声器（线上会议）**：截取系统正在播放的声音（WASAPI loopback）。
     开会前确认 Teams 扬声器输出走系统默认设备。
     只录到线上对方的声音，你自己的发言不会进入记录。
   - **麦克风（现场对话）**：采集系统默认麦克风，适合面对面开会/线下沟通。
     会录到**你自己的声音**（中文发言直接显示原文，不翻译），
     所以请把手机/音箱等外放声音关掉，否则也会被录进来。
3. 填写会议名 → 点"开始记录"
4. 字幕浮窗可拖拽，滚轮调字号；在说话人表格里把声纹标签改成真实名字
5. 会议结束 → 点"结束并生成纪要"，产物在 `会议记录/日期_时间_会议名/` 下

### 低延迟模式（云端识别）

本地识别攒批进行，字幕延迟 30~55 秒。想接近实时（约 **5~10 秒**）可切到 Groq 云端识别：

1. 到 https://console.groq.com 免费注册，创建 API key（形如 `gsk_xxx`，免费额度约 20 次/分钟）
2. 在 `.env` 里改两行：
   ```ini
   ASR_PROVIDER=groq
   GROQ_API_KEY=gsk_你的key
   ```
3. 重新启动程序即可，不用改其他配置（`ASR_BATCH_SECONDS`/`ASR_BATCH_MAX_WAIT` 只在本地模式生效）

代价与注意事项：

- **音频会上传到 Groq 云端**（本地模式全程不上传）；译文的隐私边界见文末「已知限制」
- 免费额度限速约 20 次/分钟：正常会议（每 5~10 秒一句）够用；语速密集到每分钟
  超过 20 条语句时可能触发限速 → 该句识别失败并在状态栏告警（原文缺失，不影响后续）
- 云端不可用时不会自动回退本地：把 `ASR_PROVIDER` 改回 `local` 或留空即可恢复
- 首次使用不必下载 whisper 模型（云端识别不加载本地模型）

### 两种模式怎么选

| 场景 | 选哪个 | 说明 |
|---|---|---|
| Teams / 腾讯会议 / Zoom 等线上会议 | 扬声器（线上会议） | 只录对方声音，无回声、无自己发言的重复记录 |
| 面对面会议、线下访谈 | 麦克风（现场对话） | 需离麦克风近一些；多人围坐时可考虑外接会议麦 |

> **注意（回声/重复记录）**：**Teams 会议时千万不要用麦克风模式**。
> 麦克风会把外放的对方声音一并收进来（音质与识别都会变差），同时还会录到你
> 自己 —— Teams 请用扬声器模式。
> **注意（隐私）**：麦克风模式会录到本机周围的所有人声，请在征得在场人员同意后使用。

## 已知限制

- **字幕延迟**：本地模式按 30 秒音频/35 秒墙钟成批进行，字幕延迟约 30~55 秒、
  成批出现（一批的字幕同时刷出，取决于机器负载）；连续对话能跟上实时
  （不再丢音频）。要 5~10 秒延迟请用上面的「低延迟模式（云端识别）」
- 云端模式的识别结果依赖网络：断网/限速时该句会丢（状态栏告警），不会自动回退本地
- 说话人区分基于声纹聚类，多人抢话时准确率下降；同一人超过 5 分钟不发言
  再开口可能被标为新标签
- 声音来源二选一：扬声器模式只捕获系统播放的声音（不含你的麦克风）；
  麦克风模式只捕获默认麦克风（不含系统播放的声音）。
  想同时录「线上对方 + 现场自己」需要第三方虚拟声卡混音，当前未支持
- 麦克风模式依赖系统默认输入设备：切换 USB 麦/耳机麦后需重启程序重新探测
- 翻译文本发送到 OpenCode Go 云端；识别默认全程本地，只有显式设
  `ASR_PROVIDER=groq` 时音频才会上传 Groq
